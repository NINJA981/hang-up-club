How it’s made

  1. The decision

    Train judgement, not reflex. 8 of the 20 call scripts are real calls, and the scheduler keeps about 4 in 10 daily calls ordinary. The 20 scripts expand to 1,317 playable variants.

  2. The obvious version

    Speak every line with the phone’s own voice at call time. That depends on whatever voices a phone happens to have, and it can’t give a call the narrow, slightly noisy sound of a real phone line.

  3. The trick

    Every line is voiced at build time by a free local text-to-speech engine, band-passed to 300–3,400 Hz telephone sound, and shipped as 16 kbps Opus. The whole library is 3.8 MB, and an iPhone gets an AAC copy.

  4. How it degrades

    Offline after the first download. Captions on every call. If audio can’t play, your phone’s own voice reads it. If there’s no voice, the call is a read-along.

  5. Stack and license

    React, Vite, Web Audio, IndexedDB. MIT licensed.

Each script maps to a scam category in the FTC and FBI reports and cites its page. See {{repo_source_link}}.

Read it, run it, fork it.

Hang Up Club is MIT licensed. Every call script is a plain YAML file you can read, and pnpm check fails a script that has no source or uses a real bank’s name. To add one for your own family, add a file and run the check.

Run it from source

Needs Node 24 and pnpm 10. Clone the repository, then:

pnpm install
pnpm dev
pnpm build && pnpm preview
pnpm check

The second command serves the app on a local port. The third builds the offline version. The last one checks every script’s sources, names and audio.
