# Audio credits

Every clip and ambience bed in this folder is generated by `pnpm audio:render` from the scripts in
`scenarios/`. No third-party recordings or samples are used.

| Engine | Used for | Notes |
|---|---|---|
| Windows SAPI (System.Speech) | All clips in the Stage 2 render: voices Microsoft Zira Desktop and Microsoft David Desktop | OS text-to-speech. **Open question before launch:** confirm that Microsoft's terms allow redistributing speech synthesised with these voices. Piper with a CC BY voice (for example `en_US-libritts_r-medium`) is the clean alternative and is already supported by `pnpm audio:render` when installed. |
| Piper | Not used yet | Build tool only (GPL-3.0-or-later). Its output is not a derivative of its code. Credit the voice model's author here when used. |
| Kitten TTS | Not used yet | Apache-2.0 model. Depends on the GPL-3.0 espeak-ng phonemizer, so it stays a build tool. |

Post-processing: ffmpeg (band-pass 300-3400 Hz, compression, 8 kHz round trip, loudness normalisation),
then Opus/WebM and AAC/M4A. The exact chain is `scripts/lib/tts/filter.ts`.
